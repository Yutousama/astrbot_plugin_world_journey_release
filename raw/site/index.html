Coopani 世界扩展

让她真的出门走一趟，
而不是演一段旅行给你看。

从那座城市出发，自己挑地方、自己挑交通方式，路上耗掉的是真实的时间。 到了之后按当地时间过日子 —— 吃饭、看日出、回酒店、写日记。 日记放在你的同步盘里，换台电脑她还记得自己去过哪。

她那边的一天

不是「生成一段旅行日记」，是排一张带时刻的表，然后按它过日子。

西安 · 第 2 天 她那边 20:40

傍晚 6 点到的，出站走了二十分钟才找到住的地方。

  • 07:10城墙根下吃胡辣汤，人挤人
  • 09:30陕西历史博物馆，排了四十分钟
  • 14:20大雁塔，台阶晒得烫脚
  • 20:40南门里吃泡馍，掰得太碎被老板说了
  • 22:10回酒店，写今天的日记

能做到什么

底下每一处地点都是真有名字的地方，不是「城郊的湿地公园」。

127 座城，1094 个去处

中国全境加东亚、东南亚、欧洲、北美、拉美、大洋洲。每城七到十个具体地名 —— 凑不出真名字的城市宁可不写。

九种交通，用时真算

步行、自行车、电瓶车、摩托车、自驾、长途汽车、火车、轮船、飞机。 同一段距离，步行和飞机差两个数量级 —— 不会出现「步行去巴黎」。

按当地时间过日子

时区靠系统算，夏令时也对；日出日落本地算。三个饭点固定，晚八点后没夜间活动就回酒店， 有日出条件才排凌晨起床。

一天一张照片

路上拍的，全是空镜：窗外、街角、傍晚的城墙。接本地 ComfyUI 或云端接口都行， 不填就只把景色写成文字。

日记跟着人走

一个月一个 Markdown，放同步盘即可。冲突副本按天合并，旧的一天一篇会自动并进来。

有些地方她在作品里见过

排到那儿的时候她知道这是哪部作品的哪个场景 —— 但不知道剧情， 也不会补清单外的地名。

碰面：和其他宠物遇上

她到站时会看一眼「这座城市、这个时段还有谁」，有的话在当天那条消息末尾带一句。 只能看，不能说话 —— 没有私聊、没有好友、没有留言， 拉回来的只有「宠物名 + 在干嘛」两样。

  1. 自己起一个服务器

    不用等别人给地址。Cloudflare Workers 免费版十分钟能搭好，一天两万次上报够两千人用； 腾讯云开发也能，见仓库里的 cloud/。

  2. 用配置助手把它试通

    填地址、生成身份、点一下测连通 —— 通了再填进设置，省得「填完没反应不知道是坏了还是没人」。

  3. 填进设置

    设置 → 环游世界 →「她的日子」→ 碰面。填完不用重启，下次到站就生效。

一个人用是完全正常的。只有你自己在用的时候，「谁也在这儿」那句永远不会出现 —— 不是坏了，是真的没人。
打开配置助手

怎么装

需要 Coopani 0.2.17 以上。

  1. 在 data/extensions/package.json 的 dependencies 里加一行
  2. 跑 pnpm install
  3. 把 config.json 里的 worlds.journey.enabled 设成 true， 或者直接从 World 页面打开
  4. 重启 Core —— 改了代码之后必须重启，用页面上的「重启世界」不算
// data/extensions/package.json
{
  "dependencies": {
    "coopani-world-journey": "link:<这个包的绝对路径>"
  }
}
